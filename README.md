# JULE1 Desktop Universal Browser 1.0

Desktop browser package for Windows, macOS, and Linux.

## Upload to GitHub
Upload every file and folder in this package to the root of the JULE1 repository, preserving `.github/workflows/build-desktop.yml`.

After upload, open **Actions → Build JULE1 Desktop Universal Browser → Run workflow**.

Download results from the completed workflow:
- `JULE1-Browser-Windows`
- `JULE1-Browser-macOS`
- `JULE1-Browser-Linux`

## Local test
Install Node.js, then run:

```bash
npm install
npm start
```
